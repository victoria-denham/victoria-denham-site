The problem

Legacy chaos with no way out.

The organisation had accumulated years of resources across multiple spreadsheets — different formats, inconsistent tagging, duplicated entries, no clear ownership. Nobody was sure which version of a document was current.

Publishing anything to the website meant manually reformatting data, copy-pasting between sheets, and exporting in a specific format that nobody had properly documented. It took hours. It was error-prone. It was the kind of process that only one person understood.

As the library grew, the problem compounded. More resources meant more duplication, more inconsistency, and more time lost.

What was going wrong

  • ✕ Data spread across legacy sheets with no structure
  • ✕ Duplicate entries throughout the library
  • ✕ No documented publishing process
  • ✕ Formatting manual and error-prone
  • ✕ Only one person could operate the process
What was built

One system. No complexity.

  • 01
    Resources Master workbook A single source of truth for the entire library. Designed to prevent duplication at the point of entry, with consistent tagging, filtering, and background colour logic for easy navigation.
  • 02
    Squarespace Export workbook A linked export sheet that automatically generates a CSV in the exact format required for direct Squarespace import. What previously took hours of reformatting now takes one click.
  • 03
    Legacy data migration Full audit and migration of existing legacy sheets — cleaning, deduplication, and restructuring into the new master format without losing any existing content.
  • 04
    Process documentation Full written documentation of how to use the system — so any team member can add resources, maintain the library, and publish to the website without technical knowledge.

The result: a library anyone can actually use.

  • Manual publishing process eliminated — export and import now takes under two minutes
  • Single master document means no more version conflicts or duplicate entries
  • Any team member can operate the full workflow without technical knowledge
  • Legacy data fully migrated and cleaned — nothing lost, everything structured
  • System scales — adding new resources takes seconds, not hours
