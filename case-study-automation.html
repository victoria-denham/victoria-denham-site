The problem

A manual process held together with hope.

Every week, staff were copying quotes and testimonials between a master spreadsheet, an approval document, and the live website. There was no single source of truth. Duplicates appeared constantly. Nobody was sure which version was current.

The approval process — getting content signed off before it went live — had no structure. It lived in email threads and verbal conversations. Things slipped through. Things got published twice. Things disappeared entirely.

The organisation was growing. The process wasn't. Something had to change.

What was going wrong

  • ✕ Content duplicated across 3+ documents
  • ✕ No clear approval workflow
  • ✕ Website and master list out of sync
  • ✕ Hours lost to manual data entry weekly
  • ✕ No way to scale without adding headcount
What was built

A system that thinks for itself.

  • 01
    Python scraping script Automated extraction of all existing website quote blocks — pulling live data, cleaning it, and importing it into a structured spreadsheet without any manual input.
  • 02
    Master content workbook A single source of truth for all content. Linked to the approval sheet and export pipeline, so changes propagate automatically. No more copy-pasting between documents.
  • 03
    Approval workflow system A dedicated review tab with status tracking, tone categorisation, use-case tagging, and dropdown controls. Approvals that previously took days now happen in a single structured session.
  • 04
    Automated CSV export pipeline A linked export workbook that generates a publication-ready CSV in the exact format required for direct website import. One click. No reformatting.
  • 05
    Deduplication logic Automated flagging of duplicate or near-duplicate entries across the full dataset, preventing repeated content from reaching the live site.

The result: a process that runs itself.

  • Hours of weekly manual work eliminated entirely — the Python script handles extraction automatically
  • One master document now controls everything — no version conflicts, no duplicates, no confusion
  • Approval time reduced from days of email chains to a structured same-day workflow
  • The reusable script means the system can be re-run at any time without rebuilding
  • Any team member can operate the workflow without technical knowledge
