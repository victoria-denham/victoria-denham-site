The problem

A shop masquerading as a library.

Neurodiverse Connection needed a professional resources library — academic articles, government reports, guides, research papers. The kind of authoritative knowledge hub a serious organisation needs.

What they actually had was a Squarespace shop, retrofitted with custom CSS and templates to look like a library. Every resource had to be added manually as a product listing — complete with image — through the shop backend. It was never designed for this. It was painful, slow, and producing a backlog nobody could clear.

The leadership team knew it was a problem. When I mentioned I'd spent most of a day on it, the response was: "Don't do that for more than four hours a week." The backlog at that point stretched back to early 2024.

What was broken
  • Resources added to Teams channel manually, then extracted one by one
  • Each entry uploaded individually through Squarespace shop product workflow
  • Custom image required for every single listing
  • No deduplication — duplicates accumulating across the library
  • 12-month backlog with no realistic way to clear it manually
  • Any structural change to the library meant starting from scratch
What I built

Stop doing it manually.
Build the pipeline instead.

  • 01
    Proposed the bulk upload approach Rather than continuing with individual manual uploads, I identified that Squarespace supports bulk import via CSV. I proposed switching to this workflow — and got sign-off to redesign the process entirely.
  • 02
    Exported and consolidated the entire library Pulled the full existing library export, brought it into Excel, and began deduplication. Over 400 records, many with inconsistent formatting, categories, and duplicate entries built up over years.
  • 03
    Built a Power Query mapping pipeline Used Power Query to clean and transform the data, mapping every field onto the exact column structure required by Squarespace's bulk upload CSV template. Automated what had previously been entirely manual.
  • 04
    Rebuilt the category structure Sorted through years of duplicated and inconsistent categories, rationalised them, and structured everything ready for the new library design the team wanted to implement.
  • 05
    Enabled the new CSS library redesign Because the data was now clean and consistently structured, the team were able to implement a new third-party CSS plugin for the library redesign — something that would have been impossible with the previous state of the data.

The result: a library that actually works.

  • Twelve months of backlog cleared — over 400 records migrated cleanly into the rebuilt library
  • Manual individual uploads replaced with a one-click bulk import pipeline
  • Duplicate entries eliminated through Power Query deduplication
  • Clean, consistent data structure enabled a full library redesign with new CSS implementation
  • Future resources can be added in batches in minutes, not uploaded one by one over days
